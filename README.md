# CargoBid

A full-stack cargo bidding platform where shippers post cargo and transporters place competitive quotes.

## Tech Stack

**Frontend:** React.js, Tailwind CSS, Axios  
**Backend:** Node.js, Express.js  
**Database:** MongoDB

## Features

- JWT Authentication (Shipper & Transporter roles)
- Shipper can post cargo shipments
- Transporter can view available cargos
- Transporter can place price quotes
- Shipper can accept best quote
- Protected routes based on user role
- Error handling on all forms

## How to Run

### Backend
cd server
npm install
npm start

### Frontend
npm install
npm run dev
